This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Running the app

This is a zero-build prototype — open `Event Composer.html` directly in a browser (no server needed, no npm install). All dependencies load from CDN (React 18, Babel standalone, Font Awesome).

```
open "Event Composer.html"
```

Because Babel transpiles JSX in-browser at load time, file changes are reflected immediately on refresh. There is no build step, no test suite, and no linter configured.

## Architecture

The app is a **single-page React prototype** rendered entirely from one HTML entry point. Scripts are loaded in dependency order via `<script type="text/babel">` tags:

1. `composer/components.jsx` — Robin UI primitives (`Btn`, `Input`, `Field`, `Avatar`, `Tag`, `Switch`, `Checkbox`, `AIChip`, etc.). All exported to `window`.
2. `composer/data.jsx` — Mock data (`ORGANIZER`, `PEOPLE_POOL`, `ROOMS`, `DESKS`, `SERVICES`) and utilities (`fmtTime`, `fmtTimeShort`, `buildSuggestions`). All exported to `window`.
3. `composer/chrome.jsx` — App shell: `Sidebar` (nav), `TopBar`, `MapCanvas` (schematic floor plan with `RoomRect` and `Desk` components), `MapFilters`, `MapLegend`.
4. `composer/find-time.jsx` — Availability logic: `FindTimePanel`, `InlineTimeSuggestions`, `suggestSpace`. Contains `buildTimeSlots` which computes per-slot conflicts from attendee busy blocks.
5. `composer/recurring.jsx` — Two variants of recurring event UI: `RepeatDropdown` (standard select) and `SeriesCadenceBuilder` (day chips + mini month grid + series health).
6. `composer/composer.jsx` — The main `Composer` drawer component and its sub-components: `PeopleSection`, `SpaceCard`, `SuggestedSpaceCard`, `SpacesList`.
7. `tweaks-panel.jsx` — Reusable `TweaksPanel` shell + controls (`TweakRadio`, `TweakToggle`, `TweakSlider`, etc.) and the `useTweaks` hook. Designed to work embedded in the Omelette prototype host.
8. `composer/app.jsx` — Root `App` component, `SuccessPanel`, and `ReactDOM.createRoot` mount.

Because there is no bundler, **cross-file communication is done via `window`** — each file ends with `Object.assign(window, { ... })` to expose its exports.

## Key design patterns

**Tweaks system**: `TWEAK_DEFAULTS` in `app.jsx` (inside `/*EDITMODE-BEGIN*/…/*EDITMODE-END*/` markers) controls default variant values. The `useTweaks` hook syncs state with the Omelette host via `window.parent.postMessage`. Tweaks drive which variant renders for `surface`, `inlineSuggest`, `moreTimesStyle`, `recurring`, and `density`.

**Availability model**: Time is represented as a decimal hour float (e.g. `14.5` = 2:30 PM). Busy blocks are `[start, end]` tuples on each person/room. `buildTimeSlots` in `find-time.jsx` walks the 8–18 window in 30-minute steps to score conflicts.

**Space suggestion**: `suggestSpace` in `find-time.jsx` auto-selects the tightest-fitting available non-request-only room once guests are added and no space is chosen.

**Map geometry**: Room rectangles on the floor plan use percentage-based coordinates (`rx`, `ry`, `rw`, `rh`) stored in the `ROOMS` data in `data.jsx`. Desk pod positions are generated by `buildDesks()`.

## Styling

All design tokens (colors, spacing, typography, shadows, radii) live in `colors_and_type.css` as CSS custom properties. The brand font is Brown LL (self-hosted from `fonts/`); Hanken Grotesk is the fallback. All component styles are written as inline style objects — there are no CSS modules or utility classes.

The AI/suggestion aesthetic uses a magenta→blue gradient (`#BE1F77` → `#2774C1`) on sparkle icons, gradient borders, and gradient-text spans.
